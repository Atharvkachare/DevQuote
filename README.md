# ✨ DevQuote

> A modern and responsive developer quote generator built with React.js and Vite.

DevQuote is a lightweight web application that fetches random developer/programming quotes using a REST API and displays them in a clean, modern interface.

Users can generate a new quote, copy the current quote to their clipboard, and enjoy a responsive experience across desktop and mobile devices.

🔗 **Live Website:**

## ✨ Features

- 🎯 Random developer quotes
- 🔄 Generate a new quote instantly
- 📋 Copy quotes to clipboard
- ⚡ Fast and lightweight Vite setup
- ⏳ Loading state while fetching data
- ❌ Error handling with retry functionality
- 📱 Fully responsive design
- 🧩 Reusable React components
- 🌐 REST API integration
- 🎨 Modern dark-themed UI
- 🚀 Deployed on Vercel
